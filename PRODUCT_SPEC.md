# Product Specification

## 1. Цель продукта

Сделать максимально простой персональный мобильный web app / PWA для ведения силовых тренировок в зале с телефона.

Приложение не должно заранее усложняться функциями, которые не нужны для MVP.

## 2. Архитектурные ограничения MVP

- мобильный web app / PWA;
- без регистрации и аккаунтов;
- без серверной авторизации;
- данные хранятся локально на устройстве;
- backend не используется, если он не нужен;
- простая архитектура, подходящая для vibe coding и дальнейшего расширения.

## 3. Основная модель

Структура данных:

`Тренировка → Упражнение → Подход`

Сущности:

- `Exercise` — справочник упражнения;
- `Workout` — тренировка;
- `WorkoutExercise` — упражнение внутри конкретной тренировки;
- `Set` — подход.

### Подход

Для каждого подхода хранятся:

- вес;
- количество повторений;
- RIR — необязательно;
- выполнен / не выполнен.

Вес может быть 0. Подходы с весом 0 не учитываются в тренировочном объёме.

### Историческая независимость

Завершённая тренировка хранит snapshot:

- названия упражнения;
- основной группы мышц;
- дополнительных групп мышц.

Редактирование или удаление упражнения в справочнике не должно менять старые тренировки.

## 4. Активная тренировка

При добавлении упражнения автоматически создаются 3 подхода.

Пользователь может:

- добавлять подход;
- удалять подход;
- менять вес;
- менять количество повторений;
- указывать RIR;
- отмечать подход выполненным или невыполненным;
- удалять упражнения;
- менять порядок упражнений;
- быстро создавать новое упражнение прямо во время тренировки;
- завершать тренировку даже с пустыми подходами.

При добавлении нового подхода вес копируется из предыдущего.

Результат прошлого выполнения упражнения показывается рядом с соответствующим текущим подходом. Прошлый результат только отображается и автоматически в текущую тренировку не копируется.

Суперсеты не используются.

## 5. Упражнения

В стартовой базе — 30 основных упражнений.

Каждое упражнение содержит:

- название;
- основную группу мышц;
- дополнительные группы мышц.

Пользователь может:

- создавать упражнения;
- редактировать любые упражнения;
- удалять упражнения.

Поиск и фильтры упражнений в MVP не нужны.

## 6. История

Отдельный экран истории тренировок.

Возможности:

- открыть любую тренировку;
- посмотреть все упражнения и подходы;
- редактировать завершённую тренировку;
- удалить тренировку;
- повторить прошлую тренировку как основу новой.

На главном экране должна быть кнопка «Повторить последнюю тренировку».

## 7. Статистика

Отдельный экран статистики.

Периоды:

- неделя;
- месяц;
- 3 месяца;
- 6 месяцев;
- год;
- всё время;
- произвольный диапазон дат.

Показываются:

- общий тренировочный объём;
- объём по основным группам мышц;
- сравнение с предыдущим аналогичным периодом.

В статистике упражнение относится только к основной группе мышц.

Не входят в MVP:

- общее количество подходов;
- общее количество повторений;
- частота упражнений;
- рекорды;
- 1RM;
- график активности по дням;
- длительность тренировок.

## 8. Главные экраны

1. Главная.
2. История.
3. Упражнения.
4. Статистика.
5. Активная тренировка.

На главном экране:

- большая кнопка «Начать тренировку»;
- кнопка «Повторить последнюю тренировку»;
- последняя тренировка.

## 9. Что исключено из MVP

Без отдельного согласования не добавлять:

- кардио;
- таймер отдыха;
- разминочные подходы;
- суперсеты;
- шаблоны тренировок;
- рекорды;
- 1RM;
- питание;
- вес тела;
- Apple Health;
- AI-функции;
- социальные функции;
- комментарии;
- регистрацию;
- аккаунты;
- серверную авторизацию.
