# Fitness — дневник силовых тренировок

Простой персональный дневник силовых тренировок для использования в зале с телефона.

## Текущий статус

Этап 6 — «Статистика» завершён:

- общий тренировочный объём;
- объём по основным группам мышц;
- периоды: неделя, месяц, 3 месяца, 6 месяцев, год и всё время;
- произвольный диапазон дат;
- сравнение с предыдущим аналогичным периодом;
- в объём попадают только выполненные подходы с весом больше нуля;
- упражнение относится только к своей основной группе мышц.

Этапы 1–5 также завершены. Данные хранятся локально на устройстве.

Подробные требования находятся в [PRODUCT_SPEC.md](./PRODUCT_SPEC.md), план — в [DEVELOPMENT_PLAN.md](./DEVELOPMENT_PLAN.md), текущее состояние — в [CURRENT.md](./CURRENT.md).
