# Fitness — дневник силовых тренировок

Простой персональный дневник силовых тренировок для использования в зале с телефона.

## Текущий статус

Этап 7 — «Полировка» завершён. MVP готов:

- улучшен мобильный ввод;
- веса поддерживают десятичные значения с шагом 0,1 кг;
- отображение объёма сохраняет дробную часть;
- добавлено резервное копирование данных в JSON;
- добавлено восстановление данных из JSON;
- сохранены локальная архитектура и отсутствие аккаунтов/backend.

Функциональность MVP: активная тренировка, справочник упражнений, история, прошлые результаты и статистика.

Подробные требования находятся в [PRODUCT_SPEC.md](./PRODUCT_SPEC.md), план — в [DEVELOPMENT_PLAN.md](./DEVELOPMENT_PLAN.md), текущее состояние — в [CURRENT.md](./CURRENT.md).
