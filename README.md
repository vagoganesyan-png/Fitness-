# Fitness — дневник силовых тренировок

Простой персональный дневник силовых тренировок для использования в зале с телефона.

## Текущий статус

Этап 4 — «История» завершён:

- список завершённых тренировок;
- просмотр упражнений и подходов;
- редактирование завершённой тренировки;
- удаление тренировки;
- повторение прошлой тренировки как основы новой;
- кнопка «Повторить последнюю» на главной;
- при повторении сохраняется структура упражнений, но подходы создаются пустыми;
- все изменения сохраняются локально на устройстве.

Полный справочник упражнений и активная тренировка уже работают. Статистика и отображение прошлых результатов будут добавляться на следующих этапах.

Подробные требования находятся в [PRODUCT_SPEC.md](./PRODUCT_SPEC.md), план — в [DEVELOPMENT_PLAN.md](./DEVELOPMENT_PLAN.md), текущее состояние — в [CURRENT.md](./CURRENT.md).
