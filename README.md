# Fitness — дневник силовых тренировок

Простой персональный дневник силовых тренировок для использования в зале с телефона.

## Текущий статус

Этап 3 — «Упражнения» завершён:

- создан полноценный экран справочника;
- доступны все 30 стартовых упражнений;
- можно создавать упражнения;
- можно редактировать упражнения;
- можно удалять упражнения;
- можно быстро создать упражнение прямо во время тренировки;
- при быстром создании упражнение сразу добавляется в текущую тренировку;
- история защищена snapshot названия и групп мышц упражнения.

Активная тренировка, справочник и локальное хранение работают без аккаунтов и backend. История и статистика будут добавляться на следующих этапах.

Подробные требования находятся в [PRODUCT_SPEC.md](./PRODUCT_SPEC.md), план — в [DEVELOPMENT_PLAN.md](./DEVELOPMENT_PLAN.md), текущее состояние — в [CURRENT.md](./CURRENT.md).
