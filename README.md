# Fitness — дневник силовых тренировок

Простой персональный дневник силовых тренировок для использования в зале с телефона.

## Текущий статус

Этап 2 — «Активная тренировка» завершён:

- можно начать и продолжить тренировку;
- при добавлении упражнения создаются 3 подхода;
- можно изменять вес, повторения и необязательный RIR;
- можно отмечать подход выполненным или невыполненным;
- можно добавлять и удалять подходы;
- вес нового подхода копируется из предыдущего;
- можно удалять и менять порядок упражнений;
- тренировку можно завершить даже без упражнений и подходов;
- изменения сохраняются локально на устройстве.

Активная тренировка работает на основе моделей, созданных на Этапе 1. Справочник упражнений, история и статистика будут добавляться на следующих этапах.

Подробные требования находятся в [PRODUCT_SPEC.md](./PRODUCT_SPEC.md), план — в [DEVELOPMENT_PLAN.md](./DEVELOPMENT_PLAN.md), текущее состояние — в [CURRENT.md](./CURRENT.md).

## Тренировочный объём

`вес × количество повторений`

Подходы с весом 0 не учитываются в объёме.
