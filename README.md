# Fitness — дневник силовых тренировок

Простой персональный дневник силовых тренировок для использования в зале с телефона.

## Текущий статус

Этап 1 — «Основа» завершён:

- создан минимальный React/Vite mobile web app;
- добавлен PWA-манифест;
- определены модели `Exercise`, `Workout`, `WorkoutExercise`, `Set`;
- добавлено локальное хранилище данных;
- добавлена стартовая база из 30 основных упражнений;
- создан базовый экран-заглушка для проверки основы приложения.

Активная тренировка, история и статистика будут добавляться на следующих этапах.

Подробные требования находятся в [PRODUCT_SPEC.md](./PRODUCT_SPEC.md), план — в [DEVELOPMENT_PLAN.md](./DEVELOPMENT_PLAN.md), текущее состояние — в [CURRENT.md](./CURRENT.md).

## Тренировочный объём

`вес × количество повторений`

Подходы с весом 0 не учитываются в объёме. Вес 0 допускается, например для подтягиваний.
