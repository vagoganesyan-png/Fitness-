# Fitness — дневник силовых тренировок

Простой персональный дневник силовых тренировок для использования в зале с телефона.

## Текущий статус

Этап 5 — «Прошлые результаты» завершён:

- для каждого упражнения находится последнее завершённое выполнение;
- прошлые подходы показываются рядом с соответствующими текущими подходами;
- прошлые значения отображаются только для сравнения;
- прошлые значения не копируются автоматически в текущую тренировку;
- при отсутствии истории прошлый результат не показывается.

Этапы 1–4 также завершены: работают локальное хранение, активная тренировка, справочник упражнений и история.

Подробные требования находятся в [PRODUCT_SPEC.md](./PRODUCT_SPEC.md), план — в [DEVELOPMENT_PLAN.md](./DEVELOPMENT_PLAN.md), текущее состояние — в [CURRENT.md](./CURRENT.md).
