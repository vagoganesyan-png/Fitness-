# Fitness — дневник силовых тренировок

Простой персональный дневник силовых тренировок для использования в зале с телефона.

## Цель

Фиксировать тренировки по структуре:

`Тренировка → Упражнение → Подход`

Для каждого подхода сохраняются вес, повторения, необязательный RIR и статус выполнения. Данные хранятся локально на устройстве, без регистрации, аккаунтов и серверной авторизации.

## Основные возможности MVP

- активная тренировка с автоматическим созданием 3 подходов;
- добавление, удаление и редактирование подходов;
- упражнения и их порядок можно менять во время тренировки;
- быстрое создание нового упражнения;
- завершение тренировки с пустыми подходами;
- справочник упражнений со стартовой базой из 30 упражнений;
- история с просмотром, редактированием, удалением и повторением тренировок;
- показ результатов прошлого выполнения упражнения рядом с текущими подходами;
- статистика тренировочного объёма по периодам и основным группам мышц.

## Тренировочный объём

`вес × количество повторений`

Подходы с весом 0 не учитываются в объёме. Вес 0 допускается, например для подтягиваний.
