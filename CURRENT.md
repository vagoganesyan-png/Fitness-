# Current State

## Проект

Дневник силовых тренировок — репозиторий `vagoganesyan-png/Fitness-`.

Основная ветка: `main`.

## Текущее состояние

Этап 3 — «Упражнения» завершён.

## Реализовано

- экран справочника упражнений;
- отображение всех стартовых упражнений;
- создание новых упражнений;
- редактирование названия, основной и дополнительных групп мышц;
- удаление упражнений из справочника;
- быстрое создание упражнения из активной тренировки;
- автоматическое добавление быстро созданного упражнения в текущую тренировку;
- сохранение старых названий и групп мышц через snapshot в WorkoutExercise;
- локальное сохранение всех изменений.

Удаление упражнения из справочника не удаляет его из старых или текущих тренировок.
