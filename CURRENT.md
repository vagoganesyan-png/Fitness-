# Current State

## Проект

Дневник силовых тренировок — репозиторий `vagoganesyan-png/Fitness-`.

Основная ветка: `main`.

## Текущее состояние

Этап 7 — «Полировка» завершён. MVP готов.

## Реализовано

- активная тренировка;
- справочник упражнений;
- история тренировок;
- прошлые результаты;
- статистика объёма;
- мобильный UX;
- десятичные веса с шагом 0,1 кг;
- отображение дробного тренировочного объёма;
- экспорт локальных данных в JSON;
- импорт резервной копии из JSON;
- проверка формата импортируемых данных.

## Важное ограничение

Данные по-прежнему хранятся только на текущем устройстве и в текущем браузере. Для защиты от очистки данных Safari рекомендуется периодически скачивать резервную копию.
